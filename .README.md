# Project LUCID – First Run v1.0

Project LUCID – First Run v1.0 is a professional, modular, idempotent post-installation deployment tool specifically engineered for Custom ISO Windows 11 (24H2 / 25H2) setups.

---

## Clean Professional Architecture & Dual Launchers

Project LUCID organizes all internal engine scripts, modules, and configurations inside a dedicated `core/` folder, presenting the user with two clean, numbered, auto-elevating launchers:

1. **`1-Autorun.bat` (System Readiness & Tweaks)**:
   - Executes `core/LUCID_First_Run.ps1`.
   - Strictly handles system configuration: Privacy policies, Telemetry, Cortana, Windows Search, Visual/Explorer performance tweaks, Hardware Accelerated GPU Scheduling (HAGS), and OneDrive cleanup.
2. **`2-Apps.bat` (Application Deployment & Upgrades)**:
   - Executes `core/LUCID_Apps_Run.ps1`.
   - Dedicated application installer that prioritizes **Microsoft Store (`msstore`)** sources first, automatically falling back to community (`winget`) sources. Automatically installs and upgrades target packages (`Brave`, `NanaZip`, `QuickLook`, `ShareX`, `Spotify`, `Steam`).

## How to Run

1. Open the folder.
2. For system tweaks & readiness: Double-click **`1-Autorun.bat`**.
3. For application installations & updates: Double-click **`2-Apps.bat`**.
4. Click **Yes** on the Windows UAC permission prompt.
5. Select your preferred language (`1` for English [Default], `2` for Turkce).
6. Review the execution output and press Enter when finished.
