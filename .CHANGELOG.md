# Changelog - Project LUCID – First Run

All notable changes to Project LUCID – First Run are documented in this file.

## [v1.0.0] - 2026-07-29

### Added
- **Strict Decoupling of Launchers**:
  - `Autorun.bat`: Runs `LUCID_First_Run.ps1`. Strictly handles system tweaks (Privacy, Telemetry, Search, Explorer, Graphics, OneDrive cleanup). **Will NOT execute application installations.**
  - `Apps.bat`: Runs `LUCID_Apps_Run.ps1`. Strictly handles application deployment (`Brave`, `NanaZip`, `QuickLook`, `ShareX`, `Spotify`, `Steam`) and upgrades. **Will NOT execute system registry tweaks.**
- **Microsoft Store Priority**: `Apps.psm1` attempts `msstore` repository installation first, automatically falling back to community `winget` binaries when unavailable.
- **ASCII Art Headers**: Custom ASCII art logo across batch launchers and PowerShell engines.
- **Bilingual Support (EN/TR)**: Interactive language selection menu with English `[1]` default and Turkce `[2]`.
- **Complete Audit & Verification**: 100% test pass rate across all 10 PowerShell modules, configuration schemas, and AST syntax.
